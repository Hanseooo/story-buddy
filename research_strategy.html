StoryBuddy: Research Operations Blueprint

This single-file runbook covers Objective 4: manufacture a reproducible character-consistency dataset, collect blinded human labels, fine-tune the judge, and evaluate it without leaking identities or child data. It follows the accepted ADRs and preregistered protocol; it is not a prediction of the result.

1. Objective & frozen boundaries

The task is binary character consistency: compare a canonical reference with a scene and classify whether they show the same character. The research model is Qwen2.5-VL-7B-Instruct with QLoRA; the prompted gemma-3-27b-it judge remains the incumbent baseline.

  • The fine-tuned judge is an Objective 4 research outcome, never a safety moderator.
  • Annotators never see model predictions; Objective 3 book quality is judged by experts.
  • Whether the model replaces the incumbent is decided only by the preregistered deployment gate.

3. Model & Software Architecture

  • Base Model: Qwen2.5-VL-7B-Instruct (Apache-2.0, native multi-image support).
  • Method: QLoRA (4-bit quantized base weights with a trainable low-rank adapter). Hyperparameters are pinned to LoRA rank 16 and alpha 32.
  • Serving Infrastructure: The trained adapter will be served over the frozen base model using vLLM on a Modal scale-to-zero container, maintaining compatibility with the OpenAI API protocol.

Training toolchain

The architecture specification mandates LLaMA-Factory. Freeze its configuration, environment, model revision, manifest hash, and random seeds.

  • Reproducibility: train_qlora.yaml and the generated manifest are the source artifacts.
  • Serialization: Preserve the multimodal chat template and image ordering exactly.

3. Dataset Design

The dataset is manufactured specifically for pairwise identity judgments over stylized, non-human characters.

Unit of Analysis and Generalization Target

The unit of analysis and generalization target is character disjointness. The model must learn the comparative consistency task, not memorize specific character identities.

Corpus Composition & Disjoint Splitting

Splits are defined by char_id, never by pair. Every image derived from a given canonical reference belongs to exactly one split.

  • Train and validation: 30 synthetic stories: 24 train and 6 validation, with 8 train and 2 validation stories in each of cel, gouache, and cut_paper.
  • Held-out test: donated child stories only; candidates are assigned five per style before generation, with 4 Gouache / 3 Cel / 3 Cut-paper primary slots.
  • Input contract: stories are strict JSON-list records, not Python edits. Each declares an opaque ID, redacted text, roster, provenance, split, role, and one frozen style.

Natural vs. Constructed Negative Rationale

  • Natural pairs: human labels are required, including positives; reference reuse is not a free positive label.
  • Constructed negatives: zero-image-cost pairings, train only, matched on the exact style preset and species, then made hard by visual similarity.

4. Dataset Sufficiency

Learning-Curve Analysis

To determine dataset sufficiency, we conduct a 50% vs 100% data ablation on the validation set. This establishes whether the model is still learning (improving with more data) or has hit a distillation ceiling. If 50% yields identical performance to 100%, generating more data is wasteful and the dataset is sufficient.

5. Human Ground Truth

Labeling relies on a custom, blinded web UI. Annotators assess pairs and select failures from a closed taxonomy.

Annotation Ground-Truth Model

  • Independence: Every image pair is scored independently by two researchers. Annotators are blinded to each other's responses and model predictions.
  • Adjudication is Authoritative: Disagreements are surfaced to a third researcher for final adjudication. The adjudicator's decision acts as the absolute ground truth.
  • Data Preservation: The original A/B annotations are preserved alongside the final label to compute agreement statistics on pre-adjudicated data, quantifying task ambiguity.

Pilot disposition and data lock

The completed 17-pair pilot is an instrument and UX diagnostic, not a powered reliability claim and not training data. Export its agreement, adjudication, confusion, and latency diagnostics before any cleanup. Inventory both rows and private Storage objects, then delete them as one coordinated operation. Once full labeling starts, the taxonomy, schema, and UI are frozen.

7. Experimental Evaluation

Statistical Analysis Plan

  • Comparisons: Base Model vs. Fine-Tuned Model vs. Prompted Gemma Baseline.
  • Primary Metrics: Macro-F1, different_character recall, different_character precision, and balanced accuracy.
  • Secondary Metrics: Overall accuracy, JSON/schema-validity rate, inference latency, and inference cost.
  • Character-Aware Uncertainty: Bootstrapping will be conducted at the character level (sampling characters with replacement, not pairs) to compute confidence intervals, accounting for intra-character correlation.
  • Exploratory Taxonomy: Per-reason performance metrics (precision/recall/F1) to diagnose specific blind spots, where sample size permits.

8. Test-Set Discipline

The test set enforces the following strict disciplines:

  • Real-Child Only: Sourced exclusively from real, donated Grade 5-6 child writing.
  • Completely Disjoint: Character IDs in the test set never appear in train or validation sets.
  • Frozen: The test set is locked and blinded during training. Synthetic stories must never leak into the test set; doing so silently voids Objective 4.
  • Style-controlled: Each character lineage, its reference, and its scenes use one frozen preset. Overall performance is primary; per-style results are exploratory.

9. Budget & Resource Constraints

Cost and Storage Assumptions

  • Fal budget: target spend is $25; the absolute run cap is $30, including retries. Every invocation uses an explicit image budget and resumable state.
  • Storage: Supabase remains the Storage/Auth/RLS/signed-URL system under ADR-027. Any provider change requires a new accepted ADR before implementation.
  • Encoding: canonical references remain PNG; scene assets are intended to be WebP at approximately quality 82. Verify fal support first, otherwise encode on the worker with the approved Pillow path. PDFs are generated on demand.

10. Reproducibility

By freezing the training environment (LLaMA-Factory commit, uv.lock, PyTorch version, model revision hash, dataset manifest hash, random seeds), the experiment is reproducibly specified and reviewers can accurately reconstruct the training setup.

11. Threats to Validity

  • Internal Validity: Labeler bias (mitigated by blinding and independent dual-annotation); potential data leakage if strict character-disjoint splitting fails.
  • External Validity: The fine-tuned model's generalizability is limited to the specific art styles and generative model distributions present in the dataset.
  • Style Shortcut: Cross-style negatives are forbidden so the judge cannot use a preset mismatch as a shortcut for character mismatch.
  • Construct Validity: Does the closed taxonomy adequately capture all true inconsistencies without forcing unnatural categories?
  • Statistical Conclusion: Sample size limitations, particularly for rare failure reasons in the taxonomy, reducing statistical power for granular per-reason metrics.

12. Decision Criteria

The success of this objective is evaluated in two tiers:

  • Beneficial Fine-Tuning: Does the Fine-Tuned Model demonstrably outperform the Base Model?
  • Viable Replacement: Does the Fine-Tuned Model meet or exceed the performance of the Prompted Gemma Baseline, justifying its use in production given the cost and latency benefits?

13. Architectural / Ethical Constraints

  • ADR-026 (Annotation Surface): Labeling must occur in a web UI connected to secure storage rather than offline CSVs, ensuring data security for child-donated data.
  • ADR-011 (Moderation Ordering): The fine-tuned consistency judge is strictly for character consistency. Safety moderation remains gated by prompted rubrics.
  • ADR-004 (Non-Circularity): The judge is a control signal. Annotators must never see model predictions, ensuring human labels remain independent.
  • ADR-019 (Serving via vLLM): The fine-tuned QLoRA adapter must be served over the frozen base model using vLLM in a Modal container, maintaining the identical API contract.
